# web/src：前端源码入口

这里是 React 前端真正的源码。网页地址、页面、按钮、接口调用和样式都从这里逐步找到。

先看：

1. `main.tsx`：前端启动入口，创建 React 路由和全局状态。
2. `routes/`：网址对应哪个页面，例如 `/setup`。
3. `features/`：按业务拆分页面实现，例如渠道、令牌、系统设置。
4. `components/`：可复用的按钮、表格、弹窗等组件。
5. `stores/`：前端共享状态。

理解某个后台页面时，先从 `routes` 找地址，再进入对应的 `features`，最后搜索它调用的 `/api/...` 接口。
